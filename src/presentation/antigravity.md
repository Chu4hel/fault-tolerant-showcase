# Слой представления (API)

Пакет `presentation` содержит маршрутизаторы FastAPI для обслуживания внешних запросов:
- `health.py`: Проверка жизнеспособности (`/health`).
- `catalog.py`: Управление источником и публикации цитат (`/catalog/*`).
- `import_snapshot.py`: Потоковый приём полного снимка (`/import`).
- `quotes.py`: Отдача цитат читателям (`/quotes/{id}`).
- `stats.py`: Эксплуатационная сводка (`/stats`).
